# Templix — Dependencies

(NFR-SEC-08, NFR-LIC-*).

## 0. Rules for adding and updating dependencies

1. **Versions below are floors/majors, not pins.** At install time the coding agent must look up the current
   stable release in the registry, install it, and let the lockfile pin it (`pnpm-lock.yaml`, `uv.lock`).
   Do not copy version numbers from memory or from this document into manifests blindly.
2. **Cool-down:** prefer releases at least 14 days old (use `uv`'s `exclude-newer` and pnpm's
   `minimumReleaseAge` where available). Exception: security fixes.
3. **Before adding any package** answer in the PR: why not stdlib/existing dep? licence? maintenance
   (last release, open critical issues)? install-script behaviour? transitive size? Record non-obvious
   additions in §8 "Addition log".
4. **No install scripts** from untrusted packages (`pnpm` default blocks; allowlist explicitly).
5. **Audit in CI:** `pnpm audit --prod`, `pip-audit`, licence check (`license-checker` / `pip-licenses`) with
   the allow-list in §7.
6. **Boundaries:** PyMuPDF only inside `apps/server/templix/ingest/native/` (D-007). Provider SDKs only inside
   `apps/server/templix/ai/providers/`. Browser-only libraries never imported by `render-core`/`rules`.
7. Keep the dependency count small. If a requirement can be met with < 50 lines of clear code, write it.

## 7. Licence policy

- **Project licence:** AGPL-3.0 (provisional, D-007/OQ-1).
- **Allowed in core:** MIT, BSD-2/3, ISC, Apache-2.0, HPND/PIL, MPL-2.0 (as unmodified dependency), OFL-1.1 (fonts),
  AGPL-3.0 (compatible with the project licence).
- **Review required:** LGPL (dynamic linking only), GPL-2.0-only, proprietary EULAs, "non-commercial" or
  "research-only" licences (common on model weights) — must be an optional extra with a user-visible notice.
- **Forbidden in core:** licences that forbid redistribution or impose field-of-use restrictions on the code.
- Generated `THIRD_PARTY_NOTICES.md` at build time (NFR-LIC-01).

## 8. Rejected / not adopted (with reasons)

| Candidate | Reason |
|---|---|
| LiteLLM | Large transitive surface for 3 providers + 1 compatible protocol; harder to audit in a key-handling app (D-009) |
| Electron | Size/packaging cost; defer to Tauri (D-024) |
| Next.js / Remix | No SSR requirement; adds a Node server alongside Python |
| Redux Toolkit | Heavier than Zustand+Immer for this state shape |
| Konva / Fabric.js / tldraw | Canvas-based editors complicate text fidelity, DOM measuring and accessibility; we need real DOM text |
| WeasyPrint, Typst, ReportLab as the primary renderer | Would create a second renderer that diverges from preview (D-008) |
| wkhtmltopdf | Unmaintained |
| html2canvas + jsPDF | Rasterises text; poor fidelity |
| Celery + Redis | Unnecessary infrastructure (D-014) |
| ProseMirror directly | Tiptap gives a maintained, constrained wrapper |
| Hosted OCR APIs (incl. ocr.z.ai hosted API) | Documents would leave the machine (D-030) |
| Marker 2 / MinerU as default parsers | Strong text extraction but Markdown-centric and heavier; evaluate as P2 adapters, not defaults |
| Zod as second schema system | Pydantic → JSON Schema → Ajv avoids duplicate definitions (D-015) |
